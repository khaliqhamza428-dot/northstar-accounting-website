## Features

- Responsive desktop and mobile design
- Navigation between website sections
- Accounting service presentation
- Contact form with required-field validation
- Demo submission confirmation
- Mobile navigation menu

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub
- GitHub Pages

## Project Purpose

This project was developed to practise AI-assisted website creation, frontend development, responsive design, and website testing.

**Note:** Northstar Accounting is a fictional business created for demonstration purposes. The contact form does not send or store enquiries. No real client work is represented.
